# 4. Gestão Ágil — Product Backlog e Sprints

## 4.1 Framework Adotado

A HospitalTech adota o framework Scrum adaptado ao contexto acadêmico:

- Sprints de 3 semanas
- Planning + Review simplificados
- Backlog via GitHub Projects

---

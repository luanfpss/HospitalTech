## 5.2 Como o Scrum Mitiga o Risco de Atraso

O framework Scrum mitiga atrasos por meio de:

1. Sprints curtas de 3 semanas
2. Backlog priorizado (MoSCoW)
3. Daily assíncrona via WhatsApp
4. Buffer entre Sprints

Isso reduz o impacto de atrasos acadêmicos e facilita redistribuição de tarefas.

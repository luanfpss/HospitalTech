# 3. Plano de Comunicação

## 3.1 Princípios de Comunicação

A comunicação da equipe HospitalTech segue três princípios:

- Transparência
- Agilidade
- Rastreabilidade

---

## 3.2 Ferramentas e Canais

| Ferramenta | Finalidade | Frequência |
|---|---|---|
| WhatsApp | Comunicação rápida | Diária |
| Google Meet | Reuniões de Sprint | Semanal |
| GitHub Issues | Registro de tarefas | Contínua |
| Google Drive | Armazenamento | Contínua |
| Google Docs | Edição colaborativa | Conforme demanda |
| Excel / Kanban | Rastreamento de tarefas | Semanal |
